# رَكّز — مساحة مذاكرة ذكية

تطبيق ويب عربي (RTL) لتنظيم الكورسات وفيديوهات يوتيوب في مكان واحد: تابع تقدمك، سجّل ملاحظاتك، واستخدم مؤقت بومودورو — كل ذلك بدون تسجيل وبدون سيرفر.

> البيانات تُحفظ محلياً في متصفحك فقط (`localStorage`). لا يوجد حساب، ولا قاعدة بيانات، ولا يتم إرسال تقدّمك أو ملاحظاتك إلى أي خادم.

---

## المميزات

- **مكتبة كورسات ومجلدات**: تنظيم الدروس داخل كورسات ومجلدات متداخلة، عرض شبكي أو قائمة، تكرار وحذف ونقل.
- **استيراد ذكي من يوتيوب**: إضافة فيديو أو قائمة تشغيل، لصق أكثر من رابط مرة واحدة، والتحقق من صلاحية الروابط قبل الإضافة. يعمل بدون مفتاح API، ويمكن إضافة مفتاح YouTube Data API اختيارياً لتحسين جلب قوائم التشغيل.
- **مشغّل ومتابعة تقدّم**: مشغّل يوتيوب مدمج، تسجيل وقت المشاهدة تلقائياً، إكمال الدروس، واستئناف آخر موضع.
- **ملاحظات مرتبطة بالفيديو**: إضافة ملاحظات مع حفظ التوقيت، وحذفها في أي وقت.
- **مؤقت بومودورو**: جلسات تركيز وراحة، أنواع وقت (دراسة / ترفيه / بدون)، نغمات تنبيه، وصوت مخصص.
- **إحصائيات**: هدف يومي، مخطط أسبوعي، خريطة حرارية للنشاط، والتقدم حسب كل كورس — مع عرض إجمالي الوقت بالدقائق.
- **تخصيص كامل**: الوضع الداكن/الفاتح، لوحات ألوان جاهزة أو لون مخصص، العربية/الإنجليزية.
- **نسخ احتياطي واستعادة**: تصدير كل البيانات إلى ملف JSON واستيرادها لاحقاً.
- **لوحة أوامر واختصارات**: تنقل سريع بين الصفحات والإجراءات.
- **PWA**: ملف manifest وأيقونة، ويمكن تثبيت التطبيق على الشاشة الرئيسية.

## التشغيل محلياً

يتطلب **Node.js 18+** (يُفضّل 20 LTS).

```bash
npm install
npm run dev
```

ثم افتح: <http://localhost:3000>

### أوامر مفيدة

```bash
npm run dev       # تشغيل بيئة التطوير
npm run build     # فحص TypeScript ثم بناء نسخة الإنتاج في dist/
npm run preview   # معاينة نسخة الإنتاج محلياً
```

## مفتاح YouTube API (اختياري)

التطبيق يحاول جلب قوائم التشغيل عبر واجهات عامة أولاً. إذا أردت نتائج أكثر استقراراً:

1. أنشئ مفتاح **YouTube Data API v3** من Google Cloud Console.
2. افتح **الإعدادات ← مفتاح YouTube Data API** وأضفه.
3. يُحفظ المفتاح في `localStorage` داخل متصفحك فقط، ويُستخدم للاتصال المباشر بـ Google من المتصفح.

> لا تضع أي مفاتيح حقيقية داخل ملفات المشروع أو في المستودع. ملفات `.env` مستثناة في `.gitignore`.

## الخصوصية والبيانات

- كل الحالة (الكورسات، الدروس، الملاحظات، الإعدادات، الإحصاءات) تُخزَّن تحت المفتاح `rakkez-state-v1` في `localStorage`.
- لا توجد حسابات ولا تتبّع ولا إرسال بيانات إلى خادم المشروع.
- زر **تصدير النسخة الاحتياطية** في الإعدادات ينشئ ملف JSON يحتوي بياناتك — احتفظ به في مكان آمن لأنه قد يحتوي اسمك وملاحظاتك.
- **إعادة ضبط التطبيق** من الإعدادات تمسح كل البيانات المحلية نهائياً.

## النشر

المشروع تطبيق SPA، لذلك يحتاج الاستضافة إلى إعادة توجيه كل المسارات إلى `index.html`.

### Vercel

ارفع المستودع إلى GitHub ثم اربطه بـ Vercel. الإعدادات الجاهزة موجودة في `vercel.json`:

```json
{ "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }] }
```

- Build Command: `npm run build`
- Output Directory: `dist`

### Netlify

- Build Command: `npm run build`
- Publish Directory: `dist`

ملف `public/_redirects` مضمّن ويُنسخ تلقائياً إلى `dist`:

```text
/*  /index.html  200
```

### GitHub Pages

يعمل أيضاً، لكنه يحتاج ضبط `base` في `vite.config.ts` إذا نُشر على مسار فرعي، وإضافة `404.html` كنسخة من `index.html` لدعم الروابط العميقة.

## بنية المشروع

```text
Raqez/
├─ public/                  # الأيقونة، manifest، وملفات الاستضافة
├─ src/
│  ├─ components/           # مكوّنات الواجهة (المستورد، لوحة الأوامر، التخطيط…)

│  ├─ types.ts              # أنواع البيانات
│  ├─ App.tsx               # المسارات
│  ├─ main.tsx              # نقطة الدخول
│  └─ styles.css            # التصميم الكامل
├─ index.html
├─ vite.config.ts
├─ vercel.json
└─ package.json
```
